# Hyper Subproject

`hyper` is the mean-scale hyperprior route. It uses:

```text
image -> analysis RKNN/PyTorch -> y,z,means/scales -> y/z symbols -> package
package -> Python hyper decoder + image decoder -> reconstructed image
```

The shared dataset remains outside this folder:

```text
../data/train
../data/val
```

## Train

FP quality route:

```bash
cd hyper
CUDA_VISIBLE_DEVICES=0,1,2 /home/zzw/miniconda3/envs/net/bin/torchrun \
  --standalone \
  --nproc_per_node=3 \
  train.py \
  --quality-profile hyper_ms_nano_fp \
  --train-dir ../data/train \
  --val-dir ../data/val \
  --checkpoint-dir checkpoints_hyper_ms_nano_text \
  --checkpoint-interval-steps 100 \
  --eval-interval-steps 100 \
  --num-workers 4
```

QAT route, only after FP quality is acceptable:

```bash
cd hyper
CUDA_VISIBLE_DEVICES=0,1,2 /home/zzw/miniconda3/envs/net/bin/torchrun \
  --standalone \
  --nproc_per_node=3 \
  train.py \
  --quality-profile hyper_ms_nano_qat8 \
  --init-checkpoint checkpoints_hyper_ms_nano_text/best.pt \
  --train-dir ../data/train \
  --val-dir ../data/val \
  --checkpoint-dir checkpoints_hyper_ms_nano_qat8 \
  --lr 2e-6 \
  --no-amp \
  --checkpoint-interval-steps 100 \
  --eval-interval-steps 100 \
  --num-workers 4
```

## Export ONNX / RKNN

Export analysis ONNX:

```bash
cd hyper
/home/zzw/miniconda3/envs/net/bin/python tools/export_encoder_onnx.py \
  --checkpoint artifacts/checkpoints/best_hyper.pt \
  --export-mode analysis \
  --height 512 \
  --width 512 \
  --output artifacts/export/analysis_hyper_ms_nano_512x512.onnx
```

Convert FP16 RKNN:

```bash
cd hyper
/home/zzw/miniconda3/envs/rknn/bin/python tools/convert_onnx_to_rknn_512_mixed.py \
  --onnx artifacts/export/analysis_hyper_ms_nano_512x512.onnx \
  --output artifacts/export/analysis_hyper_ms_nano_512x512_fp16.rknn \
  --part analysis \
  --precision fp16 \
  --height 512 \
  --width 512
```

PTQ W8A8 mixed has shown visible quality loss on this compression model. Keep FP16 unless a later QAT checkpoint proves otherwise.

## RKNN Board Compression

Simple `.npz` compression with analysis RKNN:

```bash
cd hyper
python3 rknn/rk3588_hyper_ms_fast_compress.py \
  --rknn artifacts/export/analysis_hyper_ms_nano_512x512_fp16.rknn \
  --params params/hyper_ms_nano_entropy_params.json \
  --input image_or_dir \
  --output out_npz \
  --height 512 \
  --width 512 \
  --resize
```

CPP entropy packing route:

```bash
cd hyper
python3 rknn/rknn_hyper_ms_nano_compress.py \
  --rknn artifacts/export/analysis_hyper_ms_nano_512x512_fp16.rknn \
  --params params/hyper_ms_nano_entropy_params.json \
  --image ../samples/test.jpg \
  --output out/test.npz \
  --height 512 \
  --width 512
```

For production `.hms` packing, feed the RKNN float outputs to:

```bash
hyper/cpp/build/hyper_ms_encode_cli
```
